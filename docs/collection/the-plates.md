# The plates

Eight confirmed Felines, hung here at full size, with the catalogue entry a gallery would put beside a picture.

Every plate on this page is the real artwork: the exact bytes the public product serves for that edition, saved into this repository and served from it. Nothing was redrawn, retouched, cropped, or re-exported. The digest printed under each frame is the SHA-256 of the file your browser just loaded, so the page can be checked against itself. See [Verify a Feline](verify-a-feline.md).

## How to read a catalogue entry

| Line | What it is |
| --- | --- |
| Plate | The position in this gallery, not a rank and not a property of the Feline |
| Edition | The Feline's number in the collection, 1 through at most 3,333 |
| Medium | The artwork's real form: a vector document inscribed whole on Bitcoin |
| Dimensions | The drawing's own coordinate space. Vector art has no pixel size, so it prints at any size without loss |
| Bytes | The exact length of the artwork file served here |
| Digest | SHA-256 of those exact bytes |
| Setting odds | The frozen generator odds of this exact combination of all ten traits |
| Provenance | The inscription that carries the artwork, and when the Feline was served |

The setting odds are not a scarcity claim. Read [Traits and odds](traits-and-odds.md) before treating a large number as a large fact.

## Why these eight

They were chosen to show the recipe's range rather than to rank anything: the first plate served, four different coats, three of the four hats, a Deceased expression, a Feast Mode plate, and a table set for a node runner. Each one is a confirmed edition, so nothing here spoils a reveal. Unreleased artwork is not published anywhere, including here.
