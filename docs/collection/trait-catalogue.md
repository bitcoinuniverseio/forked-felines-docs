# Trait catalogue

Every Feline is one cat, at one table setting, described by ten traits. This page names the ten and lists the values that have actually appeared on a confirmed Feline.

## The ten traits

Each trait answers one question about the picture.

| Trait | What it decides |
| --- | --- |
| Fur | The cat's coat |
| Expression | The face |
| Tail | Where the tail went |
| Sides | What is on the plate |
| Plate | Which plate the cat is sitting in |
| Setting | How the table is laid out |
| Glass | What is in the glass, and which glass |
| Table | The table or cloth underneath everything |
| Hat | What the cat is wearing, if anything |
| Accessory | The object that came to the table |

Two of the ten can read as absent: **Hat** and **Accessory** both carry a value named `None`. That is a drawn outcome like any other, not a missing trait.

## What this list is, and is not

The catalogue below is a **census of confirmed Felines**, read from the public collection endpoint on the date printed with it. It is the honest thing this documentation can publish, and it has two limits worth stating plainly:

- **It is a floor, not the whole recipe.** The frozen recipe contains trait values that no confirmed Feline carries yet. Those values are real and they will appear, and they are deliberately not listed here, because publishing them would spoil a reveal the mint has not made. A value missing from this page has not been ruled out.
- **The counts are not the odds.** A count of how many served Felines carry a value tells you about the mint's progress. The frozen generator weight tells you how likely the value was to be drawn, ever. They are different numbers answering different questions, and only the second one is fixed. See [Traits and odds](traits-and-odds.md).

The application is the place that publishes odds. Each Feline's own page prints the frozen weight of every trait on that Feline, committed by the recipe digest on the same card.

## Where the values come from

The values are drawn from the frozen recipe, not chosen by anyone at mint time. Your wallet, your timing, and your fee rate change nothing about which Feline the next edition is. See [How the art is made](how-the-art-is-made.md).
