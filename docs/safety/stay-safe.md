# Stay safe

Bitcoin collectibles attract impersonators and drainers. The house is designed so you never have to guess whether a request is real. These are the habits that keep you safe here and everywhere else.

## The three checks before any approval

1. **Read the amount.** The wallet must show exactly the total printed on the signed quote. Not close: exact.
2. **Read the destination.** The wallet must show the payment address printed on the bill.
3. **Read the request type.** Minting asks you to approve one Bitcoin payment. Member verification asks for one labelled BIP-322 message naming this site. Nothing else exists.

If any check fails, reject. Rejecting is always free and always safe.

## Only these places are official

- `https://forkedfelines.art` and its pages
- This documentation repository and its GitHub Pages site
- The in-app support desk at `forkedfelines.art/support`

Anything else claiming to be Forked Felines is not: no "mint is moving to a new site", no "wrapped felines", no "claim portal", no support agents in DMs.

## Staff will never DM first

This is a house rule and a security control. Any direct message that opens with help, a refund, a whitelist, or an urgent problem is an attack, no matter how convincing the profile looks. Real support happens only inside the app, in a conversation you started. See [Getting support](../help/getting-support.md).

## Urgency is the tell

The house never runs surprise countdowns, last-chance windows, or expiring privileges. Real facts here move at Bitcoin speed. Anyone rushing you to sign something within minutes is manufacturing the pressure that makes people skip the three checks.

## Wallet hygiene

- Keep valuable inscriptions in a wallet that understands Ordinals, ideally one you do not browse with.
- Never enter a seed phrase into a website. There is no legitimate reason; the house has no page that asks and never will.
- Treat "test transactions", "wallet syncs", and "account validations" as thefts in progress.
