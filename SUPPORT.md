# Support

## Product support: in the app

Orders, payments, wallets, credits, refunds, and anything about a Feline you own or want: use the private in-app support desk.

**<https://forkedfelines.art/support>**

The team there can read your order's true state; the issue tracker here cannot, and posting order details publicly is bad for your privacy. See [Getting support](docs/help/getting-support.md).

## Documentation problems: here

Wrong, unclear, stale, or broken documentation belongs in this repository's issues. Use the issue forms; they ask for exactly what we need.

## Security problems: privately

See [SECURITY.md](SECURITY.md). Never in a public issue.
